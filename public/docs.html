Medios
media.animation puede incluir una secuencia de ilustraciones SVG (1,257 disponibles), GIF/video con licencia o null. Los cuadros SVG se sirven desde ApiGym; al consumir el endpoint directamente, resuelve sus rutas relativas contra la URL base de la API. El SDK incluido ya entrega URLs absolutas. Los ejercicios sin ilustración se identifican como tales; no se muestran las fotos del catálogo anterior. La fuente Flow publica una nota de procedencia limitada que debes revisar antes de usarlos para instrucción.
Caché y errores
Usa ETag con If-None-Match para recibir 304 cuando no cambie una respuesta. Los errores tienen forma {"error":{"code":"INVALID_QUERY","message":"…"}}. Solo se admiten GET, HEAD y OPTIONS. Los parámetros desconocidos o repetidos devuelven 400.
